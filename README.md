## Slogan

> Your keys stay yours; your Solana wallet agent does the work the moment you say the word.

One line, 17 words — within the 20-word limit. Creativity first: self-custody ("your keys stay yours") paired with a voice-command payoff ("the moment you say the word"); clarity second: it says exactly what the agent does for a Solana wallet.

## Run

```sh
python3 main.py
```

Writes the slogan to `$ENTRY_OUT` (file if it ends in `.txt`, otherwise `entry.txt` inside it), or `$ENTRY_OUT_DIR/entry.txt`, default `/output/entry.txt`, and prints it to stdout. Stdlib only, no network.
